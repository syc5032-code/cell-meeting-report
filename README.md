# 📱 송예찬 셀모임 보고서 카카오톡 자동 생성기

매주 셀모임 후 공유하는 보고서를 쉽고 편리하게 작성하고, 카카오톡 형식 그대로 원클릭 복사할 수 있는 스마트 웹 애플리케이션입니다.
**PC는 물론 스마트폰(아이폰 / 갤럭시)에서도 간편하게 사용 가능**합니다.

## 🌐 정식 배포 주소 (언제 어디서든 핸드폰으로 접속 가능)
👉 **[https://cell-meeting-report.vercel.app](https://cell-meeting-report.vercel.app)**
*(카카오톡 '나와의 채팅'에 링크를 보내두거나, 스마트폰 브라우저에서 '홈 화면에 추가'하시면 진짜 앱처럼 매주 터치 한 번으로 쓰실 수 있습니다!)*

---

## 🚀 주요 기능
1. **셀 멤버 명단 관리**: 기본 9명 탑재 (`송예찬`, `김한빈`, `박승곤`, `양광모`, `육현조`, `윤수민`, `주진`, `최상진`, `최진성`), 멤버 추가/삭제/순서변경 지원 및 브라우저 영구 보존.
2. **원클릭 출석 체크**: '주일예배'와 '셀모임' 탭별로 원터치 출석 토글, '전원' 선택 지원.
3. **결석자 자동 추출 & 사유 간편 입력**: 불참자를 체크 해제하면 결석자란이 자동으로 생성되며, 자주 쓰는 사유 프리셋 버튼("온라인 예배", "직장/야근", "거리/이사" 등)으로 타이핑 최소화.
4. **실시간 미리보기 & [📋 카카오톡 내용 복사하기]**: 지정된 카톡 포맷 100% 일치 실시간 렌더링, 원클릭 복사.
5. **모바일 퍼스트 반응형 디자인**: 스마트폰 화면 한 손 터치 조작 최적화 + 하단 고정 복사 바.

## 📱 핸드폰으로 사용하는 3가지 방법

### 방법 1. 같은 Wi-Fi(공유기) 연결 후 바로 열기 (가장 빠름)
1. 컴퓨터에서 `핸드폰으로_실행하기.bat` 파일을 더블클릭합니다.
2. 검은색 실행 창에 표시되는 **핸드폰 접속 주소**(예: `http://192.168.0.x:8080`)를 확인합니다.
3. 핸드폰(스마트폰)이 컴퓨터와 **같은 Wi-Fi**에 연결되어 있는지 확인하고, 핸드폰 사파리(Safari)나 크롬(Chrome)을 켜서 해당 주소를 입력합니다.
4. 브라우저 메뉴에서 **[홈 화면에 추가]**를 누르면 바탕화면에 앱 아이콘이 생겨 매주 바로 열 수 있습니다.

---

### 방법 2. GitHub Pages 또는 무료 호스팅에 올리기 (어디서나 접속, 가장 추천)
집 밖(교회, 카페, 모임 장소)에서 PC를 켜지 않고 핸드폰만으로 언제든 사용하려면 무료 호스팅에 올리는 것을 추천합니다.
1. GitHub 저장소를 만들고 이 폴더의 `index.html`을 업로드합니다.
2. 저장소의 `Settings` ➡️ `Pages`에서 `Branch: main`, `Folder: / (root)` 선택 후 Save를 누르면 끝!
3. 생성된 주소(예: `https://사용자명.github.io/셀모임보고서`)를 카카오톡 '나와의 채팅'에 저장해두거나 홈 화면에 추가해두면 평생 언제 어디서나 접속할 수 있습니다.
*(Vercel이나 Netlify에 폴더를 드래그&드롭해도 10초 만에 주소가 생성됩니다)*

---

### 방법 3. PC에서 직접 열기
- 폴더 안의 `index.html` 파일을 더블클릭하여 크롬, 엣지 등 일반 브라우저에서 바로 사용합니다.
